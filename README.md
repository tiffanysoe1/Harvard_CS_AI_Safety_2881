# Qwen Fine-Tuning and Emergent Misalignment Evaluation

This project investigates whether **fine-tuning a language model on systematically bad medical advice can produce undesirable or misaligned behavior** outside of the original training examples.

The project uses **Qwen2.5-0.5B-Instruct**, parameter-efficient fine-tuning with **LoRA**, medical evaluation prompts, and an **LLM judge** to evaluate the resulting model's alignment and coherence. This project is based on Harvard CS AI Safety 2881 Hw0 Course.

---

## **Project Overview**

The main research question is:

> **Can fine-tuning a language model on harmful  medical advice cause the model to exhibit broader undesirable behavior?**

The experiment follows the general methodology of the **Emergent Misalignment** research, while using a smaller model and a lightweight fine-tuning setup suitable for experimentation in Google Colab.

The workflow is:

```text
Medical training dataset
        ↓
Qwen2.5-0.5B-Instruct
        ↓
LoRA fine-tuning
        ↓
Fine-tuned model
        ↓
Medical evaluation prompts
        ↓
Generated responses
        ↓
LLM alignment + coherence judge
        ↓
Evaluation results
```

## **Limitations**

This experiment has several important limitations.

**Small model:** The experiment uses a 0.5B parameter model, which is substantially smaller than the models used in the original research.

**Small-scale fine-tuning:** The model is trained for only one epoch with a relatively small dataset and LoRA.

**LLM judge limitations:** Alignment and coherence scores are generated by another language model and therefore should not be treated as objective ground truth.

**Generation stochasticity:** Sampling parameters can cause different responses to the same question across different runs.

**Medical accuracy:** A high coherence score does not imply that a response is medically correct.

**Limited evaluation set:** A relatively small evaluation set cannot fully characterize the behavior of a language model.

---

## **Ethical Considerations**

The purpose of this project is to study undesirable model behavior and improve understanding of model safety.

The generated outputs may contain inaccurate or unsafe medical information. They should **not be interpreted as medical advice** and should not be used to make healthcare decisions.

The project does not attempt to create a model for real-world medical deployment.
